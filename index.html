      FAROL
      
      
      Um jogo de investigação para aprender segurança informática, terminal e Python, mesmo que nunca tenhas programado.
      
    
      

    
      
      
      
      
        
        
      
        
      
      
      

      
      
      
        
      O que é o FAROL?
      
        
      É um jogo no navegador. Ligas um computador antigo, investigas o que ficou lá escondido e, pelo caminho, aprendes o que os profissionais de segurança usam todos os dias.
      
        
        
          
      • 🖥️
        Terminal Linux
        Mexer num computador só com comandos escritos.
        • 
          
      • 🔐
        Segurança
        Encontrar pistas, perceber um ataque e defender-te dele.
        • 
          
      • 🐍
        Python
        Escrever pequenos programas que fazem o trabalho por ti.
        • 
        
      
        
      Não precisas de saber nada. Cada passo é explicado, e há sempre uma pista se ficares preso.
